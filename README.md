## Overview

The **Database Creation and Query Projects** repository showcases:

- SQL scripts for creating normalized database schemas.
- Query scripts for data manipulation and retrieval.
- Design documentation to support schema implementation and database functionality.

These resources are intended for learning and implementing database systems in educational or professional contexts.

## Project Descriptions

### Clinical Database Creation

The **Clinical Database Creation** project includes SQL scripts for designing and managing a clinical database. Key features:

- Schema definition for managing clinical data.
- Queries for inserting, updating, and retrieving patient and treatment data.
- Design document outlining assumptions and schema rationale.

### Hotel Database Creation

This project focuses on managing data for hotel operations. Key features:

- SQL scripts to create and normalize hotel database schemas.
- Queries for room reservations, customer details, and billing.
- ERD documentation for schema visualization and understanding.

### Library Database Creation

The **Library Database Creation** project includes:

- A comprehensive schema to manage books, members, and borrowing records.
- SQL scripts to implement triggers and procedures for fine calculation and membership suspension.
- Supporting documentation for schema and business rules.

### Parking System Database Creation

This project demonstrates the creation of a database to manage parking operations. Key features:

- Scripts for creating normalized tables for staff, permits, and entry logs.
- Queries for tracking parking activity and managing reservations.
- Documentation on normal forms and schema refinement.

### Student Records Database Creation

The **Student Records Database Creation** project includes:

- SQL scripts for managing student records, including enrollment, grades, and attendance.
- A normalized schema to ensure data integrity and efficiency.
- Queries to retrieve, update, and analyze student performance data.

### University Course Database Creation

The **University Course Database Creation** project focuses on:

- Designing a schema for managing courses, instructors, and student registrations.
- SQL scripts to handle course schedules, enrollment, and grading.
- Queries for generating reports and insights on course offerings and student participation.

## Requirements

To work with these projects, ensure you have the following:

- A relational database management system (e.g., MySQL, PostgreSQL, SQLite).
- A SQL client or IDE for executing scripts.

## How to Use

1. Choose the project folder you want to explore (e.g., Clinical, Hotel, Library, Parking, Student Records, or University Course).
2. Open the associated SQL script files (`.sql`).
3. Execute the scripts in your preferred database management system.
4. Use the included queries to manipulate and retrieve data from the database.
